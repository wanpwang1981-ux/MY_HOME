# 打地鼠遊戲

這是一個使用 Python 和 `tkinter` 函式庫開發的、介面美化的打地鼠遊戲。

## 特色

-   使用圖片資源，提供更吸引人的視覺體驗。
-   動態的地鼠出現時間，增加遊戲的挑戰性。
-   清晰的遊戲狀態管理（開始、遊戲中、結束）。
-   可擴充的程式碼結構，方便未來新增功能。

## 如何執行

1.  **確認您已安裝 Python 3。**

2.  **安裝必要的函式庫：**
    本專案需要 `Pillow` 函式庫來處理圖片。請執行以下命令安裝：
    ```bash
    pip install Pillow
    ```

3.  **下載專案檔案：**
    請確保 `main.py` 和 `assets` 資料夾在同一個目錄下。`assets` 資料夾中應包含 `mole.png` 和 `hole.png`。

4.  **執行遊戲：**
    ```bash
    python main.py
    ```

## 遊戲玩法

-   遊戲開始後，地鼠會隨機從洞口出現。
-   玩家需要用滑鼠點擊出現的地鼠。
-   每成功點擊一隻地鼠，分數就會增加。
-   遊戲有時間限制，時間到後遊戲結束。

## 專案結構

-   `main.py`: 遊戲主程式。
-   `assets/`: 存放遊戲所需的圖片資源。
-   `design_and_planning_notes.md`: 設計與規劃的詳細記錄。
